# Contributing

Use issues and pull requests for focused improvements. Write English UTF-8 Markdown with LF newlines, link official technical references, and distinguish recommendations from requirements. Preserve upstream attribution and license.

Do not contribute customer source, personal data, credentials, real exports or proprietary graphics. Use synthetic fixtures. Update the guide and changelog when changing tool behavior; run `python3 -m unittest discover -s tests -v` and verify Markdown links. A claim of migration parity needs reproducible evidence, not only generated code.
